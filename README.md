Privacy Policy
Pantheon Clash · Effective date: October 13, 2026

Pantheon Clash is a free browser card game about gods from five continents. This policy explains what information the game uses and where it goes. The short version: the game does not collect your personal data.

Information we collect
We do not collect, store on our servers, or sell any personal information. The game has no accounts, no sign-in, no ads, no analytics, and no tracking tools.

Information saved on your device
To remember your progress, the game uses your browser's local storage. It saves:

the highest level you have unlocked and the power upgrades you chose for your gods (key: pantheon);
your sound on/off setting (key: pmute).
This data stays in your browser. We never receive it. You can delete it at any time by clearing this site's data in your browser settings, and the game will start from level 1.

Third-party services
Google Fonts. The game loads its fonts from Google Fonts. When the page loads, your browser requests the font files from Google, which means Google receives your IP address and basic browser details. See Google's Privacy Policy.

GitHub Pages. The game is hosted on GitHub Pages. GitHub may log visitor information such as IP addresses when you load the page. See the GitHub Privacy Statement.

We do not control these services and do not receive any data from them.

Cookies
The game does not set cookies. Third-party services listed above may use their own, subject to their policies.

Children's privacy
Because the game collects no personal information, it collects none from children either. We do not knowingly ask for information from anyone of any age.

Changes to this policy
If the game changes in a way that affects privacy (for example, adding online scores), this page will be updated and the effective date above will change.
